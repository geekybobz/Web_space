JourneyBoard Narrative

This direction sits between a timeline and a storyboard. It is the strongest option if you want each milestone to feel like a chapter with room for mini-highlights, side notes, and future sub-links.

How This Prototype Reads

The left rail explains the overall arc while the right side expands each stage into a chapter card. This is useful if some milestones later need more internal structure than a simple caption card.

Story-forward Feels like a guided narrative
Supports clusters Projects can sit inside each chapter
Future-proof Easy to add PDFs and work summaries
